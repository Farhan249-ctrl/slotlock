# SlotLock Frontend

React 18 + TypeScript + Vite frontend client for SlotLock university hall booking system.

## Setup & Running

1. **Install dependencies**:
   ```powershell
   npm install
   ```

2. **Start Development Server**:
   ```powershell
   npm run dev
   ```
   The dev server runs on `http://localhost:5173` and proxies all `/api/*` calls to the Spring Boot backend at `http://localhost:8080`.

3. **Lint**:
   ```powershell
   npm run lint
   ```

4. **Production Build**:
   ```powershell
   npm run build
   ```
